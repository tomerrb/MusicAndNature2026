# Nofit 39th Anniversary - Interactive Musical Map
**מפת מסלול אינטראקטיבית - יום הולדת 39 לנופית (מוסיקה וטבע)**

מפה אינטראקטיבית מותאמת לסמארטפונים עבור מסלול "בשביל אוהד סובב נופית".
האפליקציה מאפשרת למטיילים לנווט במפה (Pinch-to-zoom / Pan), ללחוץ על תחנות מוסיקליות ולעבור ישירות לעמודי ה-YouTube של האמנים.

## 🎵 תחנות מוסיקליות לאורך המסלול
1. **תיאטרון נופי TAFTIR** - מערב השביל (שעון שמש) [ערוץ YouTube](https://www.youtube.com/channel/UCGnaI9f5z4Frc6sD6NonoQA)
2. **מרקש אקספרס** - דרום-מרכז השביל (עתיקות בית בד) [ערוץ YouTube](https://www.youtube.com/@marrakeshexpress-5748)
3. **דניאל רובין** - צפון המסלול (מצפור חיפושיות) [ערוץ YouTube](https://www.youtube.com/channel/UCZ824A30sE44oDpokVhiGTw)
4. **נבל קלטי וקלרינט** - צפון-מערב המסלול (כלי טחינה עתיקים)
5. **Templar** - צפון המסלול (ספסל צמיגים)
6. **רוח ים (חליל ונבל)** - מזרח המסלול (כניסה ראשית)

## 📱 הפעלה ושימוש
האתר בנוי כדף יחיד (Single Page Application) מבוסס Leaflet.js, ללא צורך בשרת מורכב, ומותאם באופן מלא לכל מכשיר נייד (iOS / Android).
