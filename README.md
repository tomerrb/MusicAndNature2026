# Nofit 39th Anniversary - Interactive Musical Map & Brochure
**מפה ותוכנייה אינטראקטיבית - יום הולדת 39 לנופית (מוסיקה וטבע)**

אפליקציה אינטראקטיבית מותאמת לסמארטפונים עבור מסלול "בשביל אוהד סובב נופית".
האפליקציה מאפשרת למטיילים לנווט במפה (Pinch-to-zoom / Pan), לצפות בתוכניית האירוע המלאה, ללחוץ על תחנות מוסיקליות ולעבור ישירות לעמודי ה-YouTube של האמנים.

## ✨ תכונות עיקריות
- 🗺️ **מעבר בלחיצה אחת בין מפת המסלול לתוכנייה המלאה** עם תמיכה מלאה ב-Pinch-to-zoom.
- 🎤 **תחנות מוסיקליות אינטראקטיביות** עם אנימציית פעימה ומיקומים מדויקים לאורך השביל.
- 📱 **כרטיסיית מידע מתקדמת (Bottom Sheet)** המציגה את שמות הנגנים, סגנון מוסיקלי, שעות, וכפתור ישיר ל-YouTube.
